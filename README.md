# Calcify

A fast-paced web app where users sharpen their mental math skills by solving dynamic math operations against the clock.

## Features

- **Multiple Operations**: Practice Addition, Subtraction, Multiplication, and Division.
- **Real-Time Score & Timer**: Instant feedback on answers to keep gameplay fast and challenging.
- **Difficulty Scaling**: Practice simple single-digit equations or push your limit with multi-digit operations.
- **Responsive Layout**: Designed to play smoothly on both desktop and mobile devices.

## Tech Stack

- **Frontend**: HTML5, CSS, JavaScript
- **Deployment**: GitHub Pages

## Getting Started

### Prerequisites

You only need a modern web browser (Chrome, Firefox, Safari, Edge) to run this app locally.
